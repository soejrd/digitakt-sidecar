# External-agent prompt

Open this repository and give the agent:

```text
Read AGENTS.md, TASKBOARD.md, PROGRESS.md and PLAN.md. Claim the highest-priority READY task, or the task ID assigned to you, and execute it through its acceptance criteria.

Preserve other agents' work. Separate measured results from hypotheses. When blocked, record the exact release condition and continue independent ready work. Keep dependency edits replayable and firmware assets private.

Run relevant checks, update the existing task report and task board, refresh the concise progress handoff, and commit your changes locally. Report evidence, unresolved limitations and the next action. Follow AGENTS.md for hardware actions and publishing.
```
